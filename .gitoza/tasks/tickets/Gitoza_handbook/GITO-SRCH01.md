# Search and filter walkthrough

Use this ticket while practicing **Tickets** search. It is tagged `filters` and `search` so chip filters can find it quickly.

## Steps

1. Open **Tickets** → project **Gitoza_handbook**.
2. Open search from the tree toolbar.
3. Add **Tag** = `filters` — this ticket and [[GITO-TAGS01]] should appear.
4. Add **Status** = `done` (clear tags first) — find [[GITO-DONE01]].
5. Try **Status** = `cancelled` — find [[GITO-DONE02]].
6. Try **Priority** = `high` for bugs such as [[GITO-BUG001]] and [[GITO-AUTH02]].

## Why it matters

Search runs against the local index, so filters stay fast offline. See [[wiki:W-HBK013|Search and filter tickets]].

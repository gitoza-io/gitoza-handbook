# Using tags on tickets

## What tags do

Tags are free-form labels on a ticket. Use them to filter and search in the **Tickets** search panel.

## This ticket's tags

This ticket has tags `handbook`, `filters`, and `search`. Try adding a **Tag** filter in the Tickets search panel to find it.

## Tips

- Keep tag names short and consistent (`auth`, not `authentication-feature`)
- Combine tags with **status** quick filters in the tree toolbar

# Example story — export test report

## When to pick type **story**

Use **story** for user-facing value — a capability someone needs.

## User story

As a **QA lead**, I want to **export a test run as a PDF** so that I can share results with stakeholders who do not use Gitoza.

## Acceptance criteria

- Export is available from the Test Run view
- PDF includes run title, date, and per-case results
- Failed cases show the execution comment

# Example spike — evaluate CI upload path

## When to pick type **spike**

Use **spike** for time-boxed research. The output is a **recommendation**, not shipped product code.

## Goal

Decide whether the team should upload JUnit XML to S3 or a shared cloud-drive folder for **Test Automation**.

## Time box

Two days.

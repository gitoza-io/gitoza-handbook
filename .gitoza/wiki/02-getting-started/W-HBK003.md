# Playground vs this handbook

Gitoza offers two ways to try the app without a team repo.

## Built-in Playground

- Choose **Try playground — no remote repository** when connecting.
- Sample cases and tickets are created locally on your device.
- Use **Save** to commit locally. There is no remote **Sync** or **Confirm Changes** push.

**Best for:** a quick first look at the UI.

## This handbook repo

- A real Git repository you clone from GitHub.
- Full **Sync**, **Confirm Changes**, and team-style workflow.
- Structured lessons in **Library**, **Tickets**, cases, and runs.

**Best for:** learning how Gitoza works in a real project — and for following video tutorials.

## Summary

| | Playground | Handbook repo |
|---|------------|---------------|
| Remote Git | No | Yes |
| Save / Sync | Save only | Sync + Confirm Changes |
| Content | Minimal samples | Full guided tour |

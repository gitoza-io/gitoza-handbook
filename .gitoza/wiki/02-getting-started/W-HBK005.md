# Dashboard

The **Dashboard** shows offline test metrics built from Gitoza’s local SQLite index — not from a cloud server.

## What you see

- Counts and charts derived from indexed cases and runs in this workspace
- Data that updates after Sync, Refresh, or local edits that reindex

## Try it in this handbook

1. Open **Dashboard** in the sidebar.
2. Note the metrics for project **handbook.gitoza.test**.
3. After you add or run cases (you can create your own run), use **Refresh** if numbers look stale.

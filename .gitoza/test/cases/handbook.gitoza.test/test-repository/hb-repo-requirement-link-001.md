# Navigate from case to linked ticket

## Steps

1. Open **Test Repository** → **handbook.gitoza.test** → **checkout** → **Checkout smoke test**.
2. In the case detail, locate **Requirement IDs** (`GITO-LINK01`).
3. Open ticket **Tested by and Covered by runs**.
4. Confirm **Tested by** lists this case.
5. Return to the case and switch between **Edit** and **View** if your license allows editing.

## Expected Result

Requirement IDs connect cases to planning tickets. **Tested by** on the ticket stays in sync with the case metadata.

# Create a test run inline

## Steps

1. Open **Test Run** in the sidebar.
2. Click **+** in the **Test runs** column.
3. Type a name such as `Handbook smoke` and press Enter.
4. Confirm the new run appears in the tree with no cases yet.

## Expected Result

A run is created without leaving the Test Run view. You can add cases next via the run context menu.

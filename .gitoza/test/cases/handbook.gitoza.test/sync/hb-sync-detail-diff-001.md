# Selecting a change shows detail diff

## Steps

1. On a **fork**, make a visible edit (for example change a ticket title or wiki paragraph).
2. Click **Sync** to open **Confirm Changes**.
3. Select one item from the grouped list.
4. Inspect the detail pane.

## Expected Result

The detail pane shows that item’s **diff** (before vs after) for the selected change ([[GITO-SYNC02]] AC-6).

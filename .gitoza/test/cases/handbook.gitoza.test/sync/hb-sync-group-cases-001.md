# Cases group lists changed test cases

## Steps

1. On a **fork**, edit a test case under **Test Repository** (title or steps) and wait for autosave.
2. Click **Sync**.
3. In **Confirm Changes**, locate the **Cases** group.

## Expected Result

The **Cases** group lists the changed case file(s). Other empty entity groups are omitted or empty consistently ([[GITO-SYNC02]] AC-4–AC-5).

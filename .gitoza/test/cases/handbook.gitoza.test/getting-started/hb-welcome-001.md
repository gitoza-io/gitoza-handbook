# Explore the handbook in Gitoza

## Steps

1. Open **Library** and browse folders: `01-overview`, `02-getting-started`, `03-tickets`, `04-testing`, `05-sync`, `06-authoring`.
2. Open **Tickets** → project **Gitoza_handbook** → ticket **Welcome — start here** (`GITO-PZWZHT`).
3. Open **Test Repository** → project **handbook.gitoza.test** and select this case.
4. (Optional) Create your own **Test Run** when you want to demo execution results.

## Expected Result

You can navigate the handbook content in each Gitoza view without errors.

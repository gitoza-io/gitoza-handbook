# Dashboard case counts match Test Repository

## Steps

1. Open **Dashboard** and find project **handbook.gitoza.test**.
2. Note the case count shown for the project.
3. Open **Test Repository** → **handbook.gitoza.test** and browse suites (including **test-run** and **test-repository**).
4. After creating your own test run locally, return to **Dashboard** and use **Refresh** if counts look stale.

## Expected Result

Dashboard summarizes the local index for this workspace. Counts should align with what you see in Test Repository after indexing completes.
